### [Slide 4] ขีดความสามารถของโครงงาน (Features Overview)
- **ผู้บรรยาย:** นายณัฐพงศ์ เหินหาว
- **บทพูดแนะนำ:**
  > "กระผม ณัฐพงศ์ เหินหาว รับหน้าที่อธิบายในส่วนของขีดความสามารถของระบบครับ
  > Smart File Manager Pro มาพร้อมกับ 7 เครื่องมือหลักในแถบเมนูด้านข้าง:
  > - **Dashboard:** หน้าควบคุมสรุปสถานะสุขภาพดิสก์ พร้อมมาตรวัด Tidiness Score 0–100 และกราฟแสดงการใช้งาน CPU และ RAM
  > - **File Organizer:** จัดระเบียบไฟล์อัตโนมัติ แยกตามประเภท วันที่ หรือกฎที่กำหนดเอง พร้อมระบบพรีวิวก่อนย้ายจริง
  > - **Duplicate Finder & Similar Photos:** สแกนหาไฟล์ซ้ำด้วย SHA-256 และค้นหารูปถ่ายที่คล้ายกันด้วย Perceptual Hash พร้อมแสดงภาพย่อ
  > - **Safe Cleanup:** ล้างไฟล์ขยะและโฟลเดอร์ว่างโดยส่งลงถังรีไซเคิลเท่านั้น
  > - **Bulk Renamer & Backup:** เปลี่ยนชื่อไฟล์เป็นชุดพร้อมตรวจจับชื่อชนกัน และระบบสำรองข้อมูลแบบทางเดียวที่ไม่ลบไฟล์เดิม
  > - และจุดเด่นสำคัญคือ **รองรับภาษาไทย 100%** และปรับแต่งธีมได้ถึง 6 รูปแบบครับ"

### [Slide 7] โครงสร้างของโครงงานในภาพรวม (Overall Architecture)
- **ผู้บรรยาย:** นายปฏิภาณ พิพัฒน์พิทยากุล
- **บทพูดแนะนำ:**
  > "โครงสร้างของระบบถูกออกแบบตามสถาปัตยกรรม 3 ชั้น (3-Tier Local-First Architecture) ดังนี้ครับ:
  > 1. **Presentation Layer:** พัฒนาด้วย PySide6 (Qt for Python) มีระบบธีมแบบ Dynamic และระบบแสดงผลสองภาษา
  > 2. **Application Services:** มีตัวควบคุม QThread Concurrency ทำงานเบื้องหลังเพื่อป้องกันหน้าจอค้าง มีระบบคำนวณ Hash ความเร็วสูงระดับ 1.8 GB/s และระบบป้องกันโฟลเดอร์ระบบด้วย is_protected()
  > 3. **Data & Platform Layer:** จัดเก็บประวัติและแคชลงใน SQLite ภายในเครื่อง (`sfm.db`) และเชื่อมต่อไปยัง Supabase Auth เฉพาะการยืนยันตัวตนของผู้ใช้เท่านั้น ข้อมูลไฟล์ทั้งหมดไม่เคยออกจากเครื่องครับ"

### [Slide 9] อธิบายโค้ดส่วน Core Logic & Database Persistence
- **ผู้บรรยาย:** นายทัตพร สีโส
- **บทพูดแนะนำ:**
  > "กระผม ทัตพร สีโส ขออธิบายโค้ดส่วน Core และฐานข้อมูลครับ
  > - **core.py:** เป็น Pure Python Engine ที่ไม่ขึ้นกับ UI ประกอบด้วยฟังก์ชันสแกนดิสก์แบบ Generator, ฟังก์ชันคำนวณค่าแฮช SHA-256 แบบ Streaming, และฟังก์ชันตรวจสอบ Path Traversal
  > - **db.py:** จัดการฐานข้อมูล SQLite แบบฝังในตัว ไม่ต้องลงโปรแกรมเพิ่ม มีตาราง `undo_batches` และ `undo_moves` เพื่อให้ Undo ข้ามการเปิดปิดโปรแกรมได้
  > - และมีตาราง **`hash_cache`** ที่เก็บขนาดและเวลาแก้ไขของไฟล์ ทำให้เมื่อกดสแกนไฟล์ซ้ำ โปรแกรมจะนำค่าแฮชเดิมมาใช้ทันที เพิ่มความเร็วการสแกนขึ้นถึง 3.6 เท่าครับ"

  > - ในโฟลเดอร์ **tests/** เราสร้างชุดทดสอบอัตโนมัติจำนวน **58 การทดสอบ** ครอบคลุมการทำงานของ Core Logic, ความปลอดภัยของดิสก์, ฐานข้อมูล SQLite, การทำงานของ UI, และความครบถ้วนของภาษาไทย
  > - เราสร้างโหมด **`--selftest`** ขึ้นมาใน `app.py` เพื่อให้โปรแกรมสามารถทดสอบการบูตและการแสดงผลได้โดยไม่ต้องใช้เมาส์คลิก
  > - และเราสร้างไฟล์เวิร์กโฟลว์ **GitHub Actions (`ci.yml`)** ที่จะรันเทสต์ทั้ง 58 รายการบน Linux และ Windows ทุกครั้งที่มีการแก้ไขโค้ด ช่วยการันตีว่าซอฟต์แวร์ไม่มีจุดบกพร่องครับ"
